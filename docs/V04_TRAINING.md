# Exploit Edition 0.4 source milestone

This source candidate adds a pure Kotlin replay-derived training curriculum, weak-category scheduling, model-EV-based scoring, a 13x13 class-mass matrix, and a bounded versioned offline reference codec. References require user-declared provenance and an exact decision fingerprint; no reference is claimed to be verified GTO or suitable for live-policy replacement. Imported data cannot execute code or contact external services.

Training exercises require prior hands with supported river EV analysis in saved decision-time traces. For the current file-based workflow, see the [offline solver guide](SOLVER_BRIDGE.md).
