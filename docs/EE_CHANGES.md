# River Runner EE 相对原版的完整更新

EE 版由 Richardc7 基于 shunzhe1121 的 River Runner 开发。对照基准为原仓库的 [`36ada64`](https://github.com/shunzhe1121/river-runner/commit/36ada64827fd9f3a379b2bc737b593c65746eeb1)。以下列出分叉以来已经落地的累计改动。原作署名与 MIT 许可随项目保留。[原仓库](https://github.com/shunzhe1121/river-runner)

### 开局、对手与筹码局规则

- 筹码局和单桌锦标赛均扩展到最多 9 人，保留单挑模式。首页区分「开始游戏」和「快速开始（上次设置）」，专项训练有独立入口。
- 「自定义 AI、对手与私人局」按座位设置。可指定紧凶、松凶、跟注站、紧弱、疯子或松被动等风格，也可由基准桌／混合桌分配。中文对局用中文姓名，并可选择姓名是否随打法风格变化。
- 筹码局支持逐座位起始筹码、出局后有限次数的自动重买，以及两手之间手动补到起始目标。总盈亏按最终筹码减去全部买入和补码计算。
- 可启用 2 BB 枪口位活抓盲（至少三人发牌），设定抽水比例、单手封顶及「见翻牌才抽水」。仅对可争夺底池抽水，按主池和边池分配，未被跟注的退筹不计入抽水。[规则细节](https://github.com/Richardc7/river-runner/blob/exploit-edition/docs/CASH_RULES.md)

### 对手建模与决策证据

- 提供「原版基准」和可选的动态剥削 AI。动态模式按本桌公开行动和有效机会统计入池、加注、面对再加注的反应、持续下注、面对不同尺度的下注反应等。按牌街、单挑或多人及下注尺度分组，稀样本向基准收缩，调整幅度设上限。
- 对手范围按位置与公开行动给具体两张牌组合赋权，剔除已知阻断牌，支持 13×13 范围展示。单挑、无抽水、无不兼容边池等条件满足时，在河牌估算不同合法行动的条件筹码 EV，并可比较响应假设的影响。
- 可保存行动前的基准与调整策略、公开证据、样本量和模型版本。一手一份分析文件，随该存档牌谱管理。决策视图只读取行动者当时拥有的信息，训练和分析按指纹匹配，后来的动作和公共牌不会回填到早先的建议。
- 实时策略默认关闭，可在开局时为本局启用。对应场景有已导入的外部参考时显示其来源，否则提供明确标注的启发式参考。设置集中说明策略来源。

### 牌桌、回放与盲测

- 重新分配横屏空间，固定显示当前底池、最近行动、盲注与练习数据。右侧留给行动记录与下注，策略可单独展开。座位状态标签和下注显示调整位置，减少与姓名和底牌的重叠。
- 经典、赛博朋克、美式西部与塔罗四种风格，牌桌、牌面、牌背可独立选择并预览。桌面素材按横屏比例绘制，主题色应用到牌桌控制与座位显示。
- 「逐街复盘」改称「牌局回放」。可跳到开头、结束或逐步查看，也可从行动记录跳转。底池随回放真实还原，权益百分比附图例。「继续下一手」统一放在页面底部。
- 「本步分析」解释你的实际行动和对手的公开行动。逐步显示行动前位置、是否有利位置、起始与剩余筹码、有效后手、底池、SPR、跟注价格、所需胜率、相对底池的下注尺度和仍在局的对手。对手行动解读说明可能的原因。
- 「双轨分析」并排呈现基准和调整策略，频率用图形展示。适用局面展示标明假设的模型 EV 或外部参考频率。只有启发式频率时，用模型偏离标记表达差异。
- 支持从符合条件的牌局记录直接进入盲测。先看到当时的底牌、公共牌、位置、底池和先前公开行动，提交选择后再揭晓实战与模型参考。没有可作答决策的记录不显示盲测按钮。

### 专项训练、求解器和新手指南

- 用符合条件的已保存河牌决策练习，按弱项安排题目。答题界面展示底牌、公共牌、底池、跟注价格、训练进度和选题原因。提交后单独看解析。模型、版本与牌谱标识放在可展开详情里。
- 没题时按原因引导到记录决策设置、无抽水单挑开局或相应规则配置。练习评分以已保存的模型 EV 为依据。
- 弱点报告按位置、局面、有效筹码、底池赔率与下注尺度归类并标出样本。错题间隔复习按 1、3、7、14 天安排，进度与当前存档关联。
- 13×13 翻前教练按九人桌位置、有效筹码及率先入池、面对加注或短筹码情境展示范围。河牌 What-if 可调整下注大小、弃牌率、对手范围和有效筹码，适用于受支持的单挑筹码局河牌。
- 可将合格的单挑无抽水河牌场景导出到桌面，使用 TexasSolver Console 和自行设定的范围、尺寸运行，再将结果导回。App 根据决策指纹匹配行动与频率，并标出参考来源。外部求解器及其数据须自行准备。[离线流程](https://github.com/Richardc7/river-runner/blob/exploit-edition/docs/SOLVER_BRIDGE.md)
- 中英双语指南补齐新增功能、位置和术语，可按缩写及中英文关键词搜索。扑克速算含 4/2 法则和出张算例、跟注所需胜率、纯诈唬所需弃牌率、跟注 EV、BB、有效筹码及 SPR。

### 记录、统计、结算和设置

- 牌局记录支持按牌号、位置、日期或底牌搜索，按位置、结果、模型偏离、收藏筛选。返回时保留筛选和滚动位置。行尾提示可点进回放，自动弃牌、未行动、已复盘与模型偏离有标签。可隐藏结果、导出完整牌谱或清理未收藏记录。
- VPIP、PFR、3-Bet、WTSD、W$SD 等指标显示有效分母与释义。比率通常在 50 个有效样本后显示，BB/100 在 100 手后显示。累计盈亏按时间绘图。
- 区分筹码局结算、锦标赛冠军和提前退出。提前退出时显示当时排名，冠军及相关奖励按实际赛果处理。大盲盈亏保留小数。
- 设置加入 100%／110%／120% 字号、高对比度、音效及行动震动控制、可点击的关于／隐私、GitHub 和 MIT 许可入口。训练提示和功能可独立开关，支持只重置本存档的练习及错题进度。
- 存档可导出为 ZIP，也可恢复到新槽位，包含牌谱、复盘分析、成就、训练进度及导入策略。支持读取原 H1 牌谱，新规则局使用可记录房规与实际抽水的 H2。Android 包名独立于原作，支持并存。

### 构建和发布

- 对局逻辑和机器人随机流分离，增加确定性、可见信息隔离、筹码守恒、旧牌谱、备份、九人桌及横屏界面的自动回归测试。
- GitHub CI 构建调试包并附源码提交与校验信息。正式发布使用固定签名，每次公布 APK 的 SHA-256、证书指纹和对应源码提交。
